ROLY

A tiny, stable programming language. Integer arithmetic, strings, loops, conditions, jumps — nothing else. This single page is the complete language guide.

Values

Roly has exactly three kinds of values:

  • Integers — arbitrary size, written in decimal digits: 42, 0, 1234567
  • Booleans — only produced by comparisons; there are no boolean literals
  • Strings — double-quoted, may contain any characters: "hello world"
Booleans never mix with arithmetic. x = 1 < 2 y = x + 1 is a runtime error. Types never convert into each other: "1" == 1 is simply False.

Variables

A variable is created by assignment. Names are letters, digits, and underscores, starting with a letter or underscore. There is a single global scope — blocks do not create new scopes.

x = 10
total = x * 2
_counter = 0

Compound assignment updates a variable in place with an arithmetic operation:

x += 5
x -= 3
x *= 2
x /= 2
Reading a variable before it is assigned is a runtime error: undefined variable 'x'. Division in /= floors, like all division.

Arithmetic

Four operators, with the usual precedence — multiplication and division bind tighter than addition and subtraction. Parentheses group.

1 + 2 * 3          // 7
(1 + 2) * 3        // 9
100 / 5 / 2        // 10, division is left-associative
10 - 3 - 2         // 5, subtraction is left-associative

Division always floors toward negative infinity. Division by zero is a runtime error. There is no unary minus — write 0 - 5 for negative values.

Comparisons

Comparisons produce booleans. They chain left-to-associatively at a single precedence level, below arithmetic:

3 < 5              // True
a + 1 < b * 2      // arithmetic first
"a" == "a"          // True
"a" == "b"          // False
OperatorMeaning

Ordering comparisons on strings or booleans are runtime errors. Equality across different types is False, never an error: 1 == "1" is False.

Strings

Double quotes only. Strings are single-line — a raw newline inside a string is an error. Four escapes are supported:

"hello world"
"line one\nline two"
"tab\there"
"escaped \"quote\" and backslash \\"

Strings concatenate with +, compare with == and !=, and hold any Unicode content. They are not truthy: a string used directly as a condition is an error.

Control Flow

if / else

The condition is any expression in parentheses; the body is a braced block. The else branch is optional and always takes a block.

if (x > 10) {
    y = 1
} else {
    y = 2
}

if (x == 1) { y = 10 } else { if (x == 2) { y = 20 } }
There is no else if construct — nest an if inside the else block. An integer condition works: zero is false, nonzero is true. A string condition is an error.

while

The condition is re-checked before every iteration. The body is a braced block.

i = 0
while (i < 10) {
    i += 1
}

Blocks

A bare braced block is itself a statement. Statements do not need separators — no semicolons, no special line structure. Newlines are plain whitespace.

x = 1 y = 2

{
    x += 1
    y += 2
}

break / continue

Two jump statements, legal only inside a loop body — the parser rejects them anywhere else with 'break' outside loop. They affect the innermost enclosing loop only, and they propagate out through any nested blocks and ifs.

i = 0
while (i < 100) {
    i += 1
    if (i == 5) {
        break
    }
}
i = 0
total = 0
while (i < 10) {
    i += 1
    if (i / 2 * 2 == i) {
        continue
    }
    total += i
}
  • break terminates the innermost loop
  • continue skips the rest of the body and re-checks the condition
  • statements after a jump in the same body are not executed

Functions

A function is declared with fn, a name, typed parameters, and a body that returns a value. Declarations are only allowed at the top level of a program.

fn add (a: int, b: int) {
    return a + b
}

fn greet (name: str) {
    return "hello " + name
}

x = add(2, 3)
print(greet("roly"))

Types

Parameter types are int, str, and bool. They are checked at call time — each argument must match exactly. There is no float type; a: float is a parse error. No return type is declared.

Scope

Each call gets its own local scope: parameters and newly assigned variables are local and disappear when the call ends. Global variables are readable from inside functions, and writing to an existing global updates the global. A parameter may shadow a global.

g = 10
fn f (g: int) { return g }  // parameter shadows the global
x = f(2)          // x is 2, g stays 10

Calls and recursion

A call is an expression — f(a, b) — usable anywhere a value is. Functions are pre-registered before execution, so recursion and mutual recursion work, and a function may be called before its definition appears. Recursion depth is limited to 200 calls.

fn fact (n: int) {
    if (n <= 1) { return 1 }
    return n * fact(n - 1)
}
print(fact(10))   // 3628800

return

return ends the call immediately with a value. Inside a loop, return overrides break and continue — it terminates the whole call. Multiple returns in different branches are fine. Every function must return on every path that is used — calling a function that falls off the end of its body is a runtime error. return outside a function is a parse error, just like break outside a loop.

Rules

  • argument count must match the parameter count exactly
  • each argument's type must match its annotation exactly
  • redefining a function name is an error
  • functions are not values — x = f does not work, only f(...)
  • break / continue inside a function body but outside a loop is a parse error

print

The only built-in. A statement — not an expression — taking one expression in parentheses. Values print in their plain form: integers in decimal, strings without quotes, booleans as True / False.

print("hello world")
print(42)
print(x + y)

i = 3
while (i > 0) {
    print(i)
    i -= 1
}
